# Проект
Платформа для хостинга и чтения текста длинного формата любого жанра с функционалом, аналогичным YouTube. То есть с наличием ленты, комментариев и т. п.

# Команда
Колпаков Александр, Шремф Никита, Соперников Тимофей, Кривцун Роман

# Предварительный стек
- Веб сервер: Nginx (может Caddy)
- Центральный функционал: asp.net
- База данных: PostgreSql
- Фронтенд: Blazor/Razor pages

# Задачи
- Уведомления через telegram бот
- Скачивание текста на телефон
- Встроенная в веб-приложение читалка

# Фичи
## Которые точно планируются
- Надежные авторизация, аутентификация, идентификация
- Лента
- Комментарии
- Скрытие спойлеров (как на Reddit)
- Элегантный и красивый просмотр текста
- Встроенный текстовый редактор
- Страница менеджмента контента для креейторов
- Подписки на автора и контент (подписка на следующую главу)
- Определенная степень кастомизации ленты (отключение рекоммендаций от авторов, на которых пользователь не подписался)

## Которые рассматриваются, но имплементация которых не однозначна
- Умный алгоритм ленты
- Платные тексты
- Аналитика на странице менеджмента
- Хештеги
