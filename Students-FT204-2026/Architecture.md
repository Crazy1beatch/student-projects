## Слои приложения

### Domain (Ядро системы)

> Чистая библиотека классов C#. Ноль внешних зависимостей (нет ни библиотек Telegram, ни ...). Содержит только сущности, логику валидации и интерфейсы.

#### Доменные сущности*:
* Профиль пользователя:
  * ID Telegram
  * Личные данные 
  * Статус верификации
  * Индекс надежности
  * Ссылка на объект автомобиля
* Автомобиль
  * Марка
  * Цвет
  * Госномер
* Поездная карточка
  * Идентификатор создателя (водителя)
  * Пространственная ось маршрута (гео-строка для отрисовки пути)
  * Календарный штамп (дата и точное время выезда)
  * Финансовые условия (фиксированная сумма, бартер или бесплатно)
  * Счетчик свободных мест
  * Текущий статус рейса (Ожидание / Водитель на месте / В пути / Завершен / Отменен)
  * Список привязанных пассажирских броней
* Пассажирская бронь
  * ID пассажира
  * Ссылка на конкретную поездку
  * Индивидуальная точка посадки (координата, которую пассажир выбрал на оси водителя)
  * Статус брони (На рассмотрении / Подтверждена / Отклонена / Отменена пассажиром)
* Фоновый режим (когда пассажир отправил запрос, но вблизи не нашлось водителя)
  * ID пассажира, который не нашел машину
  * Маршрут (точки А и Б) + временно окно, когда пассажиру надо уехать
* Feedback

### Application (бизнес-логика)

> Не зависит от баз данных и контроллеров. Реализует сценарии использования приложения (Use Cases). Паттерн: Команда.

* Commands (Запись): CreateTripCommand, BookPlaceCommand, CancelBookingCommand, UpdateTripStatusCommand.
* Queries (Чтение): GetAvailableTripsQuery (поиск попуток по гео-удаленности), GetUserProfileQuery.
* Интерфейсы (Contracts): Объявление интерфейсов для инфраструктуры (например, IApplicationDbContext, IMapService, INotificationService).
