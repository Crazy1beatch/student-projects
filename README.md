# CookBot — Telegram-помощник для готовки

Telegram-бот, который помогает готовить из того, что есть дома. Пользователь пишет или говорит свободным текстом — бот разбирает запрос через ИИ, подбирает рецепты из базы и показывает, что можно приготовить.

---

## Два сценария

### 1. Прямой — «есть продукты, что приготовить?»

> «У меня есть яйца, пол батона, сыр, колбаса и йогурт, 15 минут, что можно приготовить?»

1. STT распознаёт голос/текст
2. ИИ извлекает ингредиенты, время, тип блюда
3. Карточка подтверждения — правки текстом/кнопками/голосом
4. Подбор и ранжирование рецептов
5. Топ-3 с шагами и списком недостающего

### 2. Обратный — «хочу приготовить конкретное блюдо»

> «Хочу борщ» / «Что-нибудь с курицей»

1. ИИ определяет: блюдо или категория
2. Поиск по базе
3. Рецепт + список ингредиентов
4. Опционально: шоппинг-лист

---

## Ключевые принципы

- **ИИ не выдумывает рецепты** — только парсит запрос и оформляет ответ.
- **Human-in-the-loop** — пользователь подтверждает и правит список.
- **Один движок, два входа** — общая база и пайплайн.
- **Короткий диалог** — максимум 1 уточнение, остальное — допущения.

---

## Архитектура

- **Telegram Bot > STT > LLM (parse) > [Подтверждение от пользователя]**
- **> Извлечение > Поиск рецепта > Ранжирование(от 3 до 5) > Ответ**

---

## Стек (C#)

**Основное:**

- **.NET 8 / 9**
- **Telegram.Bot** — клиент Bot API
- **ASP.NET Core Web API** — backend
- **EF Core** + **Npgsql** — ORM
- **PostgreSQL + pgvector** — БД с векторным поиском
- **StackExchange.Redis** — сессии, кэш
- **Hangfire** — фоновые задачи
- **MediatR** — CQRS, хендлеры
- **FluentValidation** — валидация JSON от LLM
- **Serilog** — логирование

**ИИ и голос:**

- **OpenAI .NET SDK** / **Azure.AI.OpenAI** — LLM
- **Anthropic.SDK** — Claude (опционально)
- **Whisper API** / **Yandex SpeechKit** — STT
- Structured output через `response_format: json_schema` + десериализация в `record`-типы

**Инфраструктура:**

- Docker + docker-compose
- xUnit + FluentAssertions — тесты
- GitHub Actions — CI
