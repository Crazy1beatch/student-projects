# CookBot — Telegram-помощник для готовки

Сайт который помогает готовить и учиться готовить из того, что есть дома. Пользователь пишет или выбирает из выпадающего списка ингредиентов, время приготовления.  

Сайт подбирает рецепт из базы и показывает рецепты и спрашивает: «Начать готовку?» или «Новый запрос».  

«Начать готовку?» : Дает поэтапную инструкцию с подтверждением каждого шага и таймером на определенных из них или Дает ссылку на ютуб с видео приготовления.  
«Новый запрос»: Возвращает в начало.  
  
## **Сценарии:**  
### **1. Прямой — «есть продукты, что приготовить?»**

- Ввод ингредиентов: Т9-поле с подсказками + кнопка «выбрать из списка»
- Список валидных ингредиентов сразу
- Подбор рецептов по (фильтры)
- Топ-3 с шагами и недостающим

### **2. Обратный — «хочу приготовить блюдо»**

- Ввод названия блюда (тоже Т9/список)
- Поиск по базе
- Рецепт + список ингредиентов
- Опционально: шоппинг-лист  
### **3. Дополнительный сценарий. Интерактивная готовка через TG бота или сайт**

- После поиска рецепта появляется возможность приготовить его "По шагам" 
- Каждый шаг подтверждаете его выполнение, а также при необходимости подождать запускается таймер и напоминает при завершении готовки

### **4. Добавление рецептов — «хочу записать свой рецепт»

- В профиле выбрать «записать рецепт» 
- Заполнить поля
	- Название
	- Ингредиенты
	- Описание
- Разбить на итеративный режим (опционально)
- При желании опубликовать рецепт

А также:

- Возможность редактирования
- Сохранение черновиков

### **Ввод названия блюда (подробно)**
#### **Т9-поле:**

- Пользователь печатает «мор» → бот показывает «морковь», «морская соль», «мороженое»
- Выбор → ингредиент добавлен в список
- Список можно чистить и дополнять

#### **Выпадающий список:**

- Inline-кнопки по категориям: «Овощи», «Мясо», «Молочка» и т.д.
- Пагинация внутри категории
- Тап → добавлено

Оба способа ведут к одному `List<IngredientId>`.

## **Ключевые принципы**

- Быстрый поиск по ингредиентам
- Гибкая база рецептов - возможность добавлять свои рецепты и делиться ими с друзьями
- Помощь в готовке

## Bounded Contexts

- **Recipes** — рецепты, шаги, ингредиенты, публикация
- **Cooking** — сессии готовки, шаги, таймеры
- **Catalog** — справочник ингредиентов, категории, Т9-поиск
- **Users** — профиль, черновики, избранное, друзья
- **Integrations** — адаптеры TG/VK/MAX

---

## Domain Layer (ядро)

- **Entities**: `Recipe`, `RecipeStep`, `Ingredient`, `CookingSession`, `User`, `Draft`
- **Value Objects**: `IngredientId`, `RecipeId`, `TimerDuration`, `Quantity`, `StepNumber`
- **Aggregates**: `Recipe` (корень, шаги и ингредиенты внутри), `CookingSession`
- **Domain Events**: `RecipePublished`, `StepCompleted`, `TimerExpired`, `SessionStarted`
- **Domain Services**: `RecipeMatcher` (подбор по ингредиентам/времени), `IngredientSuggestions` (Т9)
- **Инварианты**: рецепт ≥1 шага, сессия следует порядку шагов

## Application Layer

- **Commands/Queries (CQRS через MediatR)**: `FindRecipesByIngredientsQuery`, `StartCookingCommand`, `CompleteStepCommand`, `AddRecipeCommand`
- **Handlers** — оркестрация домена, без бизнес-логики
- **DTO/Response-модели** для API и ботов
- **Ports (интерфейсы)**: `IRecipeRepository`, `IUserRepository`, `INotificationSender`, `ICookingTimerService`
- **Валидация** FluentValidation на входе команд
- **Behaviors**: логирование, транзакции, обработка Domain Events

## Infrastructure Layer

- **EF Core** — реализации репозиториев, миграции, PostgreSQL
- **Redis** — кэш ингредиентов, сессии ботов, состояние готовки
- **Messaging**: MassTransit/RabbitMQ (события + таймеры)
- **`ICookingTimerService`** — Quartz.NET/Hangfire для отложенных напоминаний
- **Интеграционные адаптеры**: `TelegramSender`, `VkSender`, `MaxSender` (общий интерфейс `IMessenger`)
- **Внешние API**: YouTube search, Т9/поиск ингредиентов

## Presentation Layer

- **`Api`** (ASP.NET Core) — REST/OpenAPI для сайта и мобильных
- **`WebApp`** — Blazor/React + SignalR для интерактивной готовки
- **`TelegramBot`**, **`VkBot`**, **`MaxBot`** — отдельные проекты-хосты, тонкие контроллеры → Application
- **`Bff`** (опционально) — агрегация и auth для сайта
- **Auth**: JWT + OAuth (VK ID, Telegram Login)
- **Общий слой `Contracts`** — DTO/DTO-события для обмена между хостами
## Ключевые интеграционные решения

- **Единый `IMessenger`** интерфейс — новые каналы (VK, MAX) подключаются как адаптеры без изменения ядра
- **Таймеры** хранятся в БД (Hangfire) + дублируются в Redis, отправка напоминаний через `IMessenger`
- **Т9 и подбор рецептов** — доменные сервисы + индексы 
- **Черновики/публикация** — состояния `Draft → Published` в агрегате `Recipe`

## Стек
